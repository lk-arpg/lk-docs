# v1.7.x
This page contains all updates between the version 1.7.0 of Lorekeeper and version 1.7.2.

## v1.7.0
[Release notes](https://github.com/lk-arpg/lorekeeper/releases/tag/v1.7.0)

### New Additions
- Add css to make images in parsed text not stretch the page, especially on mobile ([PR #37](https://github.com/lk-arpg/lorekeeper/pull/37))
- Switch artist and designer credits to using on-site usernames/IDs rather than aliases; user selection now a dropdown using selectize ([PR #37](https://github.com/lk-arpg/lorekeeper/pull/37))
- Add a function akin to character ownership updating which, on verification or viewing of a user's profile, assigns any existing character image creators with the same alias as the user to the user's ID instead - This function can also extract alias from dA URLs provided as credit to perform this operation ([PR #37](https://github.com/lk-arpg/lorekeeper/pull/37))
- Add a command to perform the same function for existing character image creators (`php artisan assign-art-credits-to-ids`) where possible (that is, where a user exists on the site with a given alias); aliases without associated accounts are converted to urls (assumes a dA account). The "alias" column can be safely dropped after this operation, if desired ([PR #37](https://github.com/lk-arpg/lorekeeper/pull/37))
- Add a helper function which formats user profile urls from various sites in the fashion of the old (username)@ dA links, and changed art/design credits to use it ([PR #37](https://github.com/lk-arpg/lorekeeper/pull/37))
- Add a config file for sites including regex to facilitate the above/easy addition of sites ([PR #37](https://github.com/lk-arpg/lorekeeper/pull/37))

### Miscellaneous
- Update masterlist/MYO masterlist search to use on-site usernames instead ([PR #37](https://github.com/lk-arpg/lorekeeper/pull/37))

### Bug Fixes
- Fix clear MYO slot name setting grammar in character manager

Pull requests merged
[PR #37](https://github.com/lk-arpg/lorekeeper/pull/37) - [itinerare](https://github.com/itinerare)
